Why Direct Print?

Odoo's standard flow for a PDF report is: click Print → a PDF downloads to your browser's downloads folder → open it → print it. For a warehouse packer printing delivery slips all day, a cashier printing invoices, or a receptionist printing visitor badges, that's three extra clicks and a cluttered downloads folder for every single document.

Direct Print Report removes the download step entirely. When a report is marked as Direct Print, Odoo renders it as HTML in a hidden frame and calls the browser's native print dialog automatically — the same dialog you'd get from Ctrl+P. No PDF file is generated or saved, and the user picks their printer and hits Print like they would for any web page.

How It Works

Three steps from install to your first instant print.

1. Install & Choose a Default

Install the module. Every report is Direct Print–enabled by default, or turn the global switch off in Settings if you'd rather opt reports in one at a time.

2. Fine-Tune Per Report

Open Settings → Technical → Reports, pick any report, and tick or untick its own Direct Print field to override the global default.

3. Click Print, Get the Dialog

From any invoice, delivery, or document, click the normal Print button. No PDF is downloaded — the browser's print dialog opens right away.

Under the Hood

HTML Report + Browser Print API: the report is loaded as qweb-html inside a hidden iframe, then window.print() is called on it — no server-side PDF rendering is triggered at all for a direct print.

Registered Report Handler: hooks into Odoo's own ir.actions.report handlers registry, so it intercepts print actions the same way Odoo's core PDF handler does — no monkey-patched buttons.

One Config Parameter, One Field: a single ir.config_parameter stores the global default and a single direct_print boolean field on ir.actions.report stores the per-report override — nothing else touches your data model.

Frequently Asked Questions

Common questions buyers usually ask before installation.

Which Odoo apps does this depend on?

Only Odoo's core base and web modules. It works alongside any app that uses standard ir.actions.report print actions — Invoicing, Sales, Inventory, HR, and more.

Does this remove the option to download a PDF?

No. Direct Print only changes what happens when a user clicks the report's Print button. You can leave any individual report's Direct Print field unticked to keep its normal PDF download behaviour, and PDF export from other menus is unaffected.

What happens if the browser blocks the print dialog?

If the browser can't open the print window (for example, strict pop-up settings), the user gets a clear on-screen notification instead of a silent failure, so they know to check their browser's print permissions for the site.

Can I control this per report instead of globally?

Yes. Every report action gets its own Direct Print checkbox under Settings → Technical → Reports, which overrides the global default from General Settings.

Which Odoo versions does this support?

Direct Print Report is available for Odoo 17, 18, and 19. It registers into Odoo's own report-handler system rather than overriding core print buttons, so behaviour is consistent across all three versions.
